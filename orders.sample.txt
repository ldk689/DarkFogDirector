# DarkFogDirector 指令文件
# 放到：<游戏目录>\BepInEx\config\DarkFogDirector.orders.txt
# 游戏内按 F10 重新载入，按 F9 导出当前星图与巢穴清单到 DarkFogDirector.dump.txt
#
# ── 语法 ────────────────────────────────────────────────────────────────
#   源 => 目标
#
#   源    星系索引    例： 5
#         星系名      例： Teldrar
#         星系索引:轨道 例： 5:0   （只针对该星系 0 号轨道的那个巢穴）
#         巢穴 astroId 例： 1000041
#
#   目标  星系索引 / 星系名 / 巢穴 astroId
#
#   目标后面加一个英文感叹号 ! ，表示「允许强制起飞」：
#   跳过原版每 1800 tick 的节奏闸门与概率闸门，只要该巢穴有装填完成的火种就立刻发射。
#
# ── 语义说明 ────────────────────────────────────────────────────────────
# 不加 ! ：只改变「火种飞向哪个星系」，「什么时候飞」完全沿用原版。
#           这是最稳的用法，建议先用这个观察效果。
# 加   ! ：连「什么时候飞」一起接管。物质不足时会等待，不会凭空造出燃料。
#
# 一个源可以写多条，后写的覆盖先写的；带轨道的规则优先于不带轨道的通配规则。
# 目标星系巢穴已满（原版每星系最多 8 个轨道）时，该条规则本次失效并回退原版随机。
#
# ── 示例（把下面井号去掉即可启用） ──────────────────────────────────────
#
# 让 5 号星系的所有巢穴，扩张目标锁定 12 号星系
#5 => 12
#
# 让 Teldrar 星系 0 号轨道的巢穴，只往 Vega 打
#Teldrar:0 => Vega
#
# 立即强推：让 3 号星系的巢穴马上向 20 号星系发射火种
#3 => 20 !
